# Muestra pseudonimizada SIGRAM-AM V1

Esta carpeta fue generada por `scripts/prepare_handoff_v1.py`.

Contiene 10 pacientes pseudonimizados, sus medicamentos priorizados, exámenes
de 2025 y el primer reporte de criterios. No contiene el identificador
institucional, números de solicitud/receta ni centros asistenciales.

Verifique la integridad antes de usar:

```powershell
python scripts/verify_handoff_v1.py
```

Uso restringido al entorno de investigación autorizado. Los resultados son
tamizajes no validados y no deben utilizarse para decisiones asistenciales.
